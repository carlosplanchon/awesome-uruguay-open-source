## Civic Tech & GovTech

- **[ATuServicio](https://github.com/datauy/ATuServicio)** - Web app for visualizing and comparing data from Uruguay's National Integrated Health System.  
  License: GPL-3.0. Status: mature / civic tech.

- **[DerechosDeEstudiantes-2](https://github.com/datauy/DerechosDeEstudiantes-2)** - Web app about student rights in Uruguay.  
  License: GPL-3.0. Status: mature / civic tech.

- **[¿Dónde Reciclo?](https://github.com/datauy/DondeReciclo-3)** - Web and mobile app for finding recycling points in Uruguay.  
  License: GPL-3.0. Status: mature / civic tech.

- **[sistema-agenda-electronica-v4](https://github.com/AGESIC-UY/sistema-agenda-electronica-v4)** - Public-sector electronic appointment scheduling system.  
  License: see repository. Status: public-sector software.

## Applications

- **[Utopía](https://github.com/ladiaria/utopia-crm)** (by *la diaria*) - Open-source CRM and CMS platform for community-based newsrooms to manage their subscriptions and content.  
  License: BSD-3-Clause. Status: mature / active.

- **[WarriorJS](https://github.com/olistic/warriorjs)** - Game for learning programming and AI concepts.  
  License: MIT. Status: mature.

## Libraries

- **[react-pdf](https://github.com/diegomura/react-pdf)** - Create PDF files using React.  
  License: MIT. Status: active.

- **[Eureka](https://github.com/xmartlabs/Eureka)** - iOS form builder written in Swift.  
  License: MIT. Status: mature / maintained.

## AI, ML & NLP

- **[Norfair](https://github.com/tryolabs/norfair)** (by Tryolabs) - Lightweight Python library for real-time multi-object tracking. Can be added to any object detector to track objects in video streams.  
  License: BSD-3-Clause. Status: maintained.

- **[simon-ai](https://github.com/xmartlabs/simon-ai)** (by Xmartlabs) - Hand-gesture recognition game using on-device machine learning with TensorFlow Lite and MediaPipe.  
  License: MIT. Status: experimental / demo.

- **[pghumor](https://github.com/pln-fing-udelar/pghumor)** - Humor detection in Spanish tweets.  
  License: see repository. Status: academic / historical.

## Developer Tools & Infrastructure

- **[Magallanes](https://github.com/andres-montanez/Magallanes)** - Deployment tool for PHP applications.  
  License: MIT. Status: mature / low activity.

- **[magic-sheet](https://github.com/jpmonettas/magic-sheet)** - Clojure/ClojureScript tool for evaluating code from spreadsheet-like documents.  
  License: EPL-1.0. Status: specialized / historical.

- **[norm-volume-uy](https://github.com/rxavier/norm-volume-uy)** - R scripts for scraping and analyzing Uruguayan laws and decrees.  
  License: GPL-3.0. Status: experimental / research data tool.

- **[cedula-uy-pdf-sign](https://github.com/carlosplanchon/cedula-uy-pdf-sign)** - CLI tool for signing PDFs locally with a Uruguayan national ID card through PKCS#11.  
  License: Apache-2.0. Status: experimental / community-maintained.

## Inclusion Criteria

A project, organization, community, or resource may be included if it meets at least one of these conditions:

- It is created or maintained by people based in Uruguay.
- It is created or maintained by a Uruguayan organization, company, university, community, or public institution.
- It is substantially relevant to Uruguay's technology, open-source, civic-tech, academic, public-sector, or open-data ecosystem.
- It has historical or educational relevance to the local ecosystem.

## Quality Guidelines

Prefer entries with:

- Public source code.
- A clear license.
- A readable README or documentation.
- Practical usefulness, adoption, educational value, or historical relevance.

Avoid adding:

- Random inactive personal repositories.
- Projects without public source code.
- Commercial services without an open-source component.
- Entries whose connection to Uruguay cannot be reasonably verified.
